# Askme

面向 UNSW Moodle 的课程学习扩展。同步所选课程后，在 Moodle 内提问、查原文、截图求解和进行可点击的选择题练习。

## 当前版本

1.12.0 · 2026.10.04.3；本机服务 `2026.10.04.chatgpt-plan.13`。本轮正式交付说明见 [FINAL_RELEASE.md](FINAL_RELEASE.md)，验证结果与限制见 [RELEASE_STATUS.md](RELEASE_STATUS.md)。

## 开始使用

1. 在 Chrome 扩展管理页加载 `D:\Askme\extension`。已有安装直接点 Askme 的重新加载，然后刷新 Moodle。
2. 本机服务由 `start-askme.ps1` 启动；启动器保留现有 ChatGPT 登录。需要手动启动时运行 `D:\Askme\start-askme-hidden.vbs`。
3. 登录 UNSW Moodle。页面默认只显示四个悬浮入口，主动点击 Open panel 或 Open session 展开。
4. 选择课程并同步，首次同步期间保持 Moodle 页打开。课程卡可查看读取明细和原文。
5. 在设置中连接 ChatGPT，日常问答及出题使用用户选定的 `gpt-5.6-luna`。本版不需要 Ollama。
6. 会话输入区点击 Folder 选择已同步课程。可以直接问问题，或输入“根据这门课的资料出三道选择题”；测验卡会出现在对话中，支持点选、判分、解析及继续提问。

四个入口分别用于课程面板、学习会话、框选截图、讲解当前页面。会话历史保存在本机，可新建和恢复；课程与账号分别存储。面板可调整宽度，设置底部显示当前页面实际构建号。

## 同步与缓存

- 保存课程页面、文件提取正文、原文链接、页码和校验信息。普通问答检索缓存，不重新下载全部课程文件。
- 点击“更新资料”才检查课程变化；完整缓存可用时通过 ETag / Last-Modified 或内容摘要复用。失败项可单独重试。
- PDF、DOCX、PPTX、XLSX、TXT、CSV 支持正文提取；大于 100 MB 的现代 Office 文件尝试按 HTTP Range 获取正文 XML，避免传输内嵌媒体。服务器必须提供稳定版本和合法分段响应。
- PDF 长页分段后仍保留原始页码；确定空白页不再计为正文失败。无文字页尝试本地 CPU OCR，引用标注 OCR；低可信、超时或未识别图片保留缺口，并提供具体原页码。
- OCR 不代表理解照片、图表或全部公式。Office 正文提取也不包含内嵌视频或图片的视觉含义。需要时使用截图提问或回查原文件。
- 当前实测限制：GSOE9820 的 Week 1 课件第 2、20 页图片封面，以及 UNSW Strategy 第 26 页图片封底，仍需回查原页。未把校徽残词当成已读标题，也未把这些页伪装为空白。
- 作业静态说明与课程日历可供备考核对；测验作答、提交表单和评分区域不进入同步范围。

这里的缓存是可检索正文，并非原始 PDF/PPTX 的永久二进制备份。同步状态和具体缺口以面板明细为准。

## AI、数据与权限

- 当前 AI 提供方为普通 ChatGPT 订阅登录连接。问答会将本轮问题、必要的对话历史、匹配课程摘录，以及主动附加的截图发送给 ChatGPT。
- 文件解析和 OCR 在本机运行；正文缓存保存在 Chrome 扩展本地存储。登录凭据由当前 Windows 用户保护，不包含在扩展 ZIP 中。
- 不支持向量 embedding；当前检索使用课程文本检索。模型、连接状态可在面板设置中查看。
- 回答附原文依据；缺少材料时应显示证据不足。练习记录用于复习安排，不代表成绩保证或客观掌握认证。
- 扩展截图使用 Chrome 可见标签页截图权限；同步范围限定到用户选择的 UNSW Moodle 课程。

## 本机服务部署

本机需要 Node.js、Python 与 PyMuPDF。既有服务登录依赖位于 `server/node_modules`；OCR 固定依赖及部署说明见 `server/ocr-runtime/README.md`，运行时从本地读取语言数据，无需下载模型。

扩展 ZIP 仅包含 `extension/`，不包含本机服务、OCR 依赖和用户数据。迁移到另一台电脑时必须同时部署服务与依赖，不能只解压扩展 ZIP。
